# Проект "Homework"

## Описание

Проект **"Homework"** — это виджет на **Python** для обработки банковских операций клиента.  
Он позволяет фильтровать и сортировать данные о транзакциях, следуя принципам **GitFlow** и стандартам **PEP 8**.  

## Функциональность

- Фильтрация операций по статусу (`EXECUTED`, `CANCELED` и т. д.).
- Сортировка операций по дате.
- Поддержка аннотаций типов, линтеров (`Flake8`, `mypy`, `isort`).
- Разработка по **GitFlow** с атомарными коммитами.

## Установка и запуск

### 1. Клонируйте репозиторий:

git clone https://github.com/EvgeniaBalatskaya/homework.git

### 2. Перейдите в директорию проекта:

cd homework

### 3. Установите зависимости:

poetry install
pip install pandas
pip install black
pip install flake8
pip install isort
pip install mypy
pip install pytest
pip install requests

## Использование  

В проекте есть основные модули:

- processing.py — фильтрация и сортировка операций.
- masks.py — маскировка номеров карт и счетов.
- widget.py — основной виджет.
- generators.ру - генерация тестовых данных, включая номера карт, описания транзакций и фильтрацию по валютам.
- decorators.py - содержит декоратор log, который логирует выполнение функций, включая аргументы, результат и ошибки, с возможностью вывода в файл или консоль.
- utils.py - модуль для обработки данных, загруженных из JSON-файла.
- external_api.py - модуль для взаимодействия с внешним API для получения данных о курсах валют и конвертации сумм.
- reader.ру - модуль предоставляет функции для считывания финансовых транзакций из CSV и Excel файлов. Он использует библиотеку `pandas` для обработки данных и возвращает список транзакций в виде словарей.
- main.ру - модуль предназначен для обработки финансовых транзакций и конвертации валют с использованием данных, полученных из CSV или Excel файлов.
- tests — тесты для проверки логики.

## Логирование

В проекте используется логирование для отслеживания важных событий и ошибок в процессе работы.
Логи записываются в файлы в директории logs, которая находится в корневой папке проекта. Логи каждого модуля (например, utils, masks) сохраняются в отдельных файлах:

- logs/utils.log – для логирования операций в модуле utils.
- logs/masks.log – для логирования операций в модуле masks.


## Тестирование
